# La Locandiera — Fès

Static website for La Locandiera, a wood-fired pizzeria in Fès ([@lalocandiera.fes](https://www.instagram.com/lalocandiera.fes/)).

Plain HTML, CSS and JavaScript, no build step. Open `index.html` or serve the folder:

```bash
python3 -m http.server 8765
```
